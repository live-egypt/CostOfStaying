# ثمن البقاء | The Cost of Staying

**وثائق المشروع — الإصدار 2.0**

لعبة بقاء نفسي جماعية؛ البقاء له ثمن، نقل المعاناة يؤخر الانهيار، والموت يغيّر دور اللاعب بدلاً من إنهاء مشاركته.

## حالة المشروع
- المرحلة: ما قبل الإنتاج (Pre-production).
- التنفيذ البرمجي: آخر حالة موثقة في v1 تقول إنه لم يبدأ؛ يلزم تحديثها عند أول commit برمجي.
- الوثائق: v2.0 على فرع `docs/v2.0`.
- المنصة الأولى: Android.
- نطاق MVP: مباراة مكتملة لأربعة لاعبين.

## المبدأ الهندسي
**لا قرار بلا سبب موثق، ولا ادعاء أداء بلا قياس، ولا تغيير حساس بلا اختبار ودليل.**

## التكدس المقترح
Unity 6.3 LTS + URP، C#، FishNet، Linux Dedicated Server. اعتماد Backend واستضافة الإنتاج مؤجل إلى ما بعد prototype ومقارنة التكلفة والكمون. راجع ADR-001 وما يرتبط به.

## حالة الوثائق
PROPOSED = مقترح، APPROVED = معتمد، TBD = غير محسوم، IMPLEMENTED = منفذ بالكود، VERIFIED = مختبر بدليل. وجود وثيقة لا يعني أن النظام نُفذ أو اختُبر أو أصبح آمناً إنتاجياً.
