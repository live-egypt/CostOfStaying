# ثمن البقاء | The Cost of Staying

**وثائق المشروع — الإصدار 2.1**

لعبة بقاء نفسي جماعية؛ كل ثانية تستنزف Vitality، ونقل المعاناة يؤخر الانهيار لكنه يضيف كلفة Betrayal، والموت ينقل اللاعب إلى دور Spirit.

## حالة المشروع
- المرحلة: ما قبل الإنتاج (Pre-production).
- الوثائق: v2.1 على فرع `docs/v2.0`.
- التنفيذ البرمجي: لم يُنفذ ضمن طلب التوثيق هذا.
- المنصة الأولى: Android.
- نطاق MVP: مباراة مكتملة لأربعة لاعبين.

## ابدأ من هنا
اقرأ [فهرس الوثائق](docs/README.md)، [ميثاق المشروع](docs/00_PROJECT_CHARTER.md)، [مواصفات قواعد اللعبة](docs/02_GAME_RULES_SPECIFICATION.md)، و[المعمارية التقنية](docs/architecture/TECHNICAL_ARCHITECTURE.md).

## خط أساس قواعد اللعب
توجد توصيات موحدة في ADR-004: Vitality تتآكل حتى الصفر؛ نقل Debuff كامل؛ تصويت استسلام جماعي بالإجماع؛ Spirit شاهد محايد؛ والفوز لآخر ناجٍ مع نهايات محددة أخرى. هذه القرارات مقترحة للاختبار وليست نهائية قبل Playtest.

## المبدأ الهندسي
**لا قرار بلا سبب موثق، ولا ادعاء أداء بلا قياس، ولا تغيير حساس بلا اختبار ودليل.**

## التكدس المقترح
Unity 6.3 LTS + URP، C#، FishNet، Linux Dedicated Server. اعتماد Backend واستضافة الإنتاج مؤجل إلى ما بعد prototype ومقارنة التكلفة والكمون.

## حالات الوثائق
PROPOSED = مقترح، APPROVED = معتمد، TBD = غير محسوم، IMPLEMENTED = منفذ بالكود، VERIFIED = مختبر بدليل. وجود وثيقة لا يعني أن النظام نُفذ أو اختُبر أو أصبح آمناً إنتاجياً.
