# ثمن البقاء (The Cost of Staying)

**Psychological Hardcore Survival Multiplayer Game**

Mobile-first (Android + iOS) — Unity + FishNet + Nakama

---

## الفكرة

البقاء له ثمن دائم. كل ثانية تستهلك منك. الطريقة الوحيدة لتأخير موتك هي نقل معاناتك إلى الآخرين. الموت لا يحررك.
