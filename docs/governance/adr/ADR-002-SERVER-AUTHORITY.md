# ADR-002 — سلطة الخادم
**الحالة: APPROVED كمبدأ أمني | التنفيذ: NOT IMPLEMENTED**

## السياق
اللعبة متعددة اللاعبين وتتضمن صحة وضرراً ونقلاً ومؤقتات وتصويتاً؛ قبول نتائج يرسلها العميل يسمح بالغش وتزوير الحالة.

## القرار
Dedicated Server هو مصدر الحقيقة لحالة المباراة. العميل يرسل Intent فقط. الخادم يتحقق ويحسب ويحدث الحالة ثم يرسل replication.

## قواعد ملزمة
- لا يقبل الخادم من العميل health/damage/ammo/transfer result/vote result/energy كقيم موثوقة.
- التحقق من الجلسة، المباراة، الحالة، المدى، التبريد، الملكية، السرعة، الذخيرة، RequestId وحدود الرسائل.
- العمليات الحساسة ذرية أو idempotent.
- ساعة الخادم هي مرجع المؤقتات.

## التحقق
اختبارات تزوير state، replay، spam، concurrent transfer، invalid target، disconnect، والرسائل المشوهة.

## الاستثناءات
لا توجد استثناءات في MVP. أي استثناء يتطلب ADR ومراجعة أمنية.
