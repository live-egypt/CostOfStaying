# ADR-003 — Backend واستضافة الخوادم
**الحالة: PROPOSED**

## السياق
FishNet طبقة نقل شبكي وليس مزود استضافة. يحتاج المشروع لاحقاً إلى قرار حول الحسابات والمطابقة والبيانات وتشغيل Dedicated Servers.

## القرار المؤقت
لا تعتمد Backend أو مزود استضافة إنتاج في مرحلة التصميم. استخدم خادم Linux تجريبياً قابلاً للتشغيل والقياس.

## خيارات للمقارنة
- PlayFab: خدمات حسابات ومطابقة وبيانات وMultiplayer Servers.
- Nakama: Backend قابل للاستضافة الذاتية مع مسؤولية تشغيل وصيانة.
- خدمة مخصصة: مرفوضة في MVP ما لم توجد حاجة غير مغطاة بالخيارات السابقة.

## معايير الحسم
RTT من مناطق الجمهور، التكلفة لكل ساعة/مباراة/لاعب، autoscaling، Linux support، lifecycle integration، حدود الخطط، portability، مراقبة، واستعادة الأعطال.

## شرط الاعتماد
prototype فعلي وقياسات اتصال وتكلفة مكتوبة. لا تجمع PlayFab وNakama في MVP دون مبرر وظيفي موثق.
