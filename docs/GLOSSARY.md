# مسرد المصطلحات — v1.0
**الحالة: REFERENCE | المصطلحات المعيارية المستخدمة في الوثائق**

| المصطلح | التعريف المعتمد في التوثيق |
|---|---|
| Alive | لاعب ما زال حياً داخل المباراة. |
| Backend | خدمات خارج خادم المباراة، مثل الحسابات والمطابقة والبيانات الدائمة. |
| Betrayal | كلفة/عاقبة يكتسبها مصدر عملية Suffering Transfer الناجحة؛ ليست نقاط فوز. |
| Collapse | حدث/مرحلة تضغط على اللاعب وتزيد معدل تآكل Vitality وتطبق Debuff وفق القواعد. |
| Dedicated Server | خادم مستقل يملك الحالة authoritative للمباراة. |
| Debuff | أثر سلبي على اللاعب له تعريف وقيمة ومدة وقابلية نقل محددة. |
| Echo Fragment | عنصر/هدف تجمعه Spirit لرفع Witness Score. |
| Endgame | قواعد التصويت وإنهاء المباراة وتحديد النتيجة. |
| Intent | طلب فعل يرسله العميل؛ لا يعد نتيجة موثوقة أو تغيير حالة. |
| MatchId | معرف فريد للمباراة يستخدم لربط الأحداث والتحقق من النطاق. |
| Move | نقل الأثر من المصدر إلى الهدف وإزالته من المصدر عند نجاح المعاملة. |
| PSS | Proportional Set Size؛ مقياس لذاكرة العملية على Android. |
| RequestId | معرف طلب يستخدم لمنع إعادة تطبيق العمليات الحساسة. |
| Spirit | دور اللاعب بعد الموت؛ شاهد محايد ذو هدف Witness مستقل. |
| Suffering Transfer | نقل آخر Debuff نشط قابل للنقل من لاعب إلى آخر وفق شروط خادمية. |
| Vitality | مورد البقاء الذي يبدأ عند 100 ويتآكل حتى الصفر. |
| Witness Score | نتيجة مستقلة للروح مبنية على Echo Fragments، لا تغير فائز المباراة. |

## قواعد التسمية
- استخدم المصطلح الإنجليزي نفسه في المعرفات التقنية وأسماء الأنظمة.
- استخدم التعريف أعلاه عند أول ظهور للمصطلح في الوثائق.
- لا تستخدم Death وCollapse كمترادفين: Collapse لا يقتل فوراً؛ الموت عند Vitality = 0.
- لا تستخدم Betrayal بمعنى نقاط الفوز أو مكافأة.
- لا تستخدم Transfer للدلالة على Copy؛ القاعدة المقترحة Move كامل.
- إذا تغير تعريف مصطلح، حدّث المسرد ومواصفات النظام والاختبارات وADR ذي الصلة.
