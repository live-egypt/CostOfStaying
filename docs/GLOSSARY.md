# مسرد المصطلحات — v2.1
**الحالة: PROPOSED | يصف مصطلحات الحزمة الحالية ولا يعتمد القواعد نهائياً**

| المصطلح | التعريف المستخدم في هذه الحزمة |
|---|---|
| Alive | لاعب ما زال حياً داخل المباراة. |
| Backend | خدمات خارج خادم المباراة، مثل الحسابات والمطابقة والبيانات الدائمة. غير معتمد في ADR-003. |
| Betrayal | كلفة يكتسبها مصدر Suffering Transfer الناجحة؛ ليست نقاط فوز. عتبات الأثر غير معتمدة. |
| Collapse | حدث يزيد معدل تآكل Vitality ويطبق Debuff. لا يقتل فوراً. |
| Dedicated Server | خادم مستقل يملك حالة المباراة. المبدأ معتمد في ADR-002 والتنفيذ غير موجود. |
| Debuff | أثر سلبي له قيمة ومدة وقابلية نقل. تفاصيل الأنواع ما زالت TBD. |
| Echo Fragment | هدف تجمعه Spirit لرفع Witness Score. |
| Endgame | قواعد التصويت وإنهاء المباراة والنتيجة وفق RULE-03 وRULE-05. |
| Intent | طلب فعل يرسله العميل؛ ليس نتيجة موثوقة. |
| MatchId | معرف المبارة المستخدم لربط الأحداث والتحقق من النطاق. |
| Move | نقل الأثر من المصدر إلى الهدف وإزالته من المصدر عند نجاح المعاملة. ليس Copy. |
| PSS | Proportional Set Size؛ مقياس ذاكرة العملية على Android. ليس ميزانية معتمدة. |
| RequestId | معرف طلب لمنع إعادة تطبيق العمليات الحساسة. |
| Spirit | دور اللاعب بعد الموت؛ شاهد محايد ذو هدف مستقل. |
| Suffering Transfer | نقل آخر Debuff نشط قابل للنقل وفق شروط خادمية. |
| Vitality | مورد البقاء يبدأ عند 100 ويتآكل حتى الصفر. |
| Witness Score | نتيجة الروح المستقلة. لا تغيّر فائز المباراة. |

## قواعد التسمية
- استخدم المصطلح الإنجليزي نفسه في المعرفات التقنية وأسماء الأنظمة.
- لا تستخدم Death وCollapse كمترادفين.
- لا تستخدم Betrayal بمعنى نقاط الفوز.
- لا تستخدم Transfer بمعنى Copy.
- إذا تغير تعريف، ححّث المسرد ومواصفة القواعد ووثيقة النظام وADR ذي الصلة.
