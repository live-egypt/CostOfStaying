# Backend and Hosting — v2.0
**الحالة: PROPOSED**

FishNet ينقل بيانات اللعبة ولا يوفر استضافة إنتاج بحد ذاته. ابدأ بخادم Linux Dedicated Server محلي/اختباري، ثم قس RTT وCPU وRAM وbandwidth وتكلفة المباراة.

PlayFab مرشح لخدمات الحسابات والمطابقة والبيانات وMultiplayer Servers. Nakama بديل قابل للاستضافة الذاتية ويضيف عبء تشغيل وصيانة. لا تجمع الاثنين في MVP بلا حاجة موثقة.

إذا اختير PlayFab MPS فيلزم دمج GSDK واختبار دورة حياة الخادم وLinux build والمناطق والتكلفة. لا تفترض أن الحصص التجريبية استضافة إنتاج مجانية.

قارن تكلفة الساعة/اللاعب، المناطق، RTT من جمهور الاختبار، التشغيل، autoscaling، portability، وحدود الخطط.
