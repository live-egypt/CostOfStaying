# Backend and Hosting — v2.1
**الحالة: PROPOSED | القرار في ADR-003 ولا يُحسم هنا**

هذه الوثيقة لا تختار مزوداً. ADR-003 يؤجل الاعتماد حتى prototype وقياسات مكتوبة. لا يُجمع PlayFab وNakama في MVP بلا حاجة وظيفية موثقة.

FishNet ينقل بيانات اللعبة ولا يوفر استضافة إنتاج. ابدأ بخادم Linux تجريبي قابل للقياس.

خيارا المقارنة، لا الترجيح:
- PlayFab: حسابات ومطابقة وبيانات وMultiplayer Servers. إذا اختير لاحقاً يلزم دمج GSDK واختبار Linux والمناطق والتكلفة. الحصص التجريبية ليست استضافة إنتاج.
- Nakama: خلفية قابلة للاستضافة الذاتية مع عبء تشغيل.

معايير المقارنة هي نفسها في ADR-003: RTT، التكلفة، autoscaling، دعم Linux، دورة حياة الخادم، حدود الخطط، قابلية النقل، المراقبة، واستعادة الأعطال.
