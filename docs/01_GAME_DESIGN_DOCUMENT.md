# Game Design Document — v2.0
**الحالة: PROPOSED**

## الملخص
The Cost of Staying لعبة بقاء نفسي جماعية. يضعف اللاعب بمرور الوقت، ويمكنه محاولة نقل معاناته إلى لاعب آخر. بعد الموت يتحول إلى Spirit بقدرات محدودة. التجربة مبنية على التوتر الاجتماعي والقرارات المكلفة.

## نطاق اللعبة
- النوع: Multiplayer Psychological Survival.
- المنصة الأولى: Android.
- النمط البصري: 3D Dark Low-Poly.
- لاعبو MVP: 4.
- مدة الجولة المستهدفة: 10–16 دقيقة، وحد 20 دقيقة مقترح.
- المنظور: TBD.

## أعمدة اللعب
Collapse، Suffering Transfer، Betrayal، Combat، Spirit، Endgame.

## تدفق المباراة
Created → Waiting → Starting → Running → Ending → Completed.
حالات اللاعب: Connecting → Alive → Dead/Spirit → Spectating أو Disconnected. الخادم يقرر الانتقالات.

## الحلقة الأساسية
استكشاف → مراقبة حالة الانهيار → تحمل Debuff أو نقله → مواجهة/تجنب اللاعبين → الموت والتحول إلى Spirit → المشاركة في النهاية → عرض نتيجة مفهومة.

## محتوى MVP
خريطة واحدة، مجموعة محدودة من Debuffs والأسلحة والقدرات، واجهة تشرح الحالة، Dedicated Server، واختبارات دورة كاملة لأربعة لاعبين.

## قرارات TBD
مصدر الموت، أثر النقل، هدف الروح وولاؤها، آلية التصويت النهائية، شروط الفوز. لا تعتمد هذه القواعد بالتخمين.
