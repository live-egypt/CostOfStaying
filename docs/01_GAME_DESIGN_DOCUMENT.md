# Game Design Document — v2.1
**الحالة: PROPOSED FOR PLAYTEST**

## الملخص
The Cost of Staying لعبة بقاء نفسي جماعية. كل ثانية تستنزف Vitality، والانهيار يزيد التآكل ويترك Debuffs. يستطيع اللاعب نقل آخر عبء قابل للنقل إلى لاعب آخر، لكنه يراكم Betrayal. الموت لا ينهي مشاركة اللاعب؛ بل يحوله إلى Spirit محايد له هدف مستقل محدود.

## نطاق اللعبة
- النوع: Multiplayer Psychological Survival.
- المنصة الأولى: Android.
- النمط البصري: 3D Dark Low-Poly.
- MVP: أربعة لاعبين، خريطة واحدة، مباراة كاملة.
- مدة الجولة المستهدفة: 10–16 دقيقة، حد أقصى أولي 20 دقيقة.
- المنظور: TBD.

## أعمدة اللعب
1. ضغط بقاء متزايد وواضح عبر Vitality وCollapse.
2. نقل المعاناة كقرار تكتيكي كامل النقل وله كلفة Betrayal.
3. Spirit دور لاحق للموت، مستقل ومحايد، لا يفسد عدالة الأحياء.
4. Dedicated Server يحسم النتائج الحساسة.
5. نهاية مفهومة: آخر ناجٍ، استسلام جماعي بالإجماع، أو نفاد الوقت/انهيار الجميع.

## الحلقة الأساسية
استكشف → راقب Vitality وموعد Collapse → تعامل مع Debuff → انقل آخر عبء أو احتفظ به → واجه/تجنب الآخرين → عند الموت العب دور Spirit واجمع Echoes → شارك في نهاية المباراة وفق حالتك → شاهد نتيجة واضحة.

## النهاية
عند بقاء ثلاثة أحياء، يفتح تصويت Collective Surrender لمدة 20 ثانية. يتطلب الإجماع؛ أي No أو امتناع يعيد المباراة إلى اللعب. الموافقة تنهي المباراة بنهاية جماعية بلا فائز فردي. خلاف ذلك، يفوز آخر لاعب حي؛ وعند انتهاء الحد الزمني يفوز صاحب Vitality الأعلى إذا بقي أكثر من لاعب.

## محتوى MVP
خريطة واحدة، أربعة لاعبين، Vitality/Collapse، مجموعة Debuffs محدودة، نقل ذري، Betrayal، Combat أساسي، Spirit/Echoes، تصويت ونهايات، Android client وLinux Dedicated Server.
