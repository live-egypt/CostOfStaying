# تجربة اللاعب والحلقة الأساسية — v2.0
**الحالة: PROPOSED**

## الوعد
كل تأجيل للانهيار له تكلفة اجتماعية أو تكتيكية. الموت يغير أسلوب المشاركة ولا يحول اللاعب إلى متفرج بلا هدف.

## الحلقة
استكشف وابحث عن موارد → راقب المؤقت والحالة → تحمل الانهيار أو انقله → قاتل أو تجنب → تحوّل إلى Spirit عند الموت → شارك في تصعيد النهاية → افهم النتيجة.

## وضوح الواجهة
اعرض Debuffs النشطة، توقيت الانهيار، شروط النقل، سبب رفض الطلب، طاقة الروح وتبريدها، حالة التصويت، وسبب نهاية المباراة.

## Onboarding
علّم الحركة، الانهيار، النقل، القتال، الموت، وقدرات الروح. اختبر فهم اللاعب بدلاً من الاكتفاء بعرض التعليمات.

## Playtest metrics
فهم قواعد النقل، أسباب فشل النقل، وقت فهم الواجهة، الانسحاب قبل النهاية، وضوح العدالة بعد الموت. سجل baseline قبل تحديد أهداف رقمية.
