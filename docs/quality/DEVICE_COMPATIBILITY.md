# Device Compatibility — v2.1
**الحالة: PROPOSED | الحد الأدنى للأجهزة TBD**

لا يوجد جهاز معتمد كحد أدنى. Redmi Note 8 ذِكر سابقاً فقط وليس متطلباً في v2.1. ثبّت الـ SKU والذاكرة وإصدار Android قبل أي ادعاء توافق.

اختبر أجهزة فعلية منخفضة ومتوسطة وعالية، وسجّل SoC وGPU وRAM وAndroid والشاشة. قس FPS والذاكرة والحرارة والبطارية واللمس والشبكة وإعادة الاتصال والتحميل والاستقرار بعد thermal throttling.

لا تعلن الحد الأدنى قبل مصفوفة أجهزة فعلية وتقرير محفوظ. هذا لا يغيّر أن منصة MVP الأولى هي Android.
