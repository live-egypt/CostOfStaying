# سيناريو 03 — شاهد الروح (Spirit Witness)
**الحالة: PROPOSED | GATE-1.1 | الوكيل: Playtest Oracle + Domain Guardian | يختبر: RULE-04 + RULE-05 + انتقال Alive→Spirit**

## الهدف
هل دور الروح محايد ومفهوم وممتع بعد الموت، لا عقوبة خروج؟ يختبر **RULE-04** (Witness محايد + Echo + Hint) وانتقال `Alive→Spirit` (ADR-023) ونهاية MutualCollapse.

## الإعداد (4 لاعبين + 1 مراقب Spirit، مباراة قصيرة 10–14د)

| العنصر | القيمة |
|---|---|
| موت | 0 Vitality → Spirit فوراً (بطاقة رمادية + يتحرك لزاوية الروح) — لا Dead نهائي في MVP |
| Spirit | لا يسبب ضرر/نقل/تصويت — يجمع Echo Fragments (حصى 5–7 مبعثرة) + تلميح عام واحد (cooldown 15ث) |
| Hint | جملة عامة يقرأها الميسر للجميع (مثال: "الرياح تشتد في الوسط") — لا تكشف إحداثيات |
| Witness Score | نقاط Echo فقط — لا تغير فائز الأحياء — تُعرض منفصلة عند MutualCollapse |
| Alive→Spirit | Resurrect معطل (ADR-023) — لا عودة — الميسر يوضح قبل البداية |

## السيناريو (يركز على الموت المبكر)

### 1) موت مبكر مصطنع (0–3د)
لاعب يبدأ متعمداً بـ Debuffs إضافية ليموت مبكراً (نُقلت إليه قبل البداية). **الملاحظ:** هل يشعر Spirit بالإقصاء أم بالفضول؟ هل يلتفت الأحياء لتلميحه؟

### 2) لعب الروح (3–10د)
Spirit يجمع Echo ويختار متى يرسل Hint. الأحياء يقررون: هل يتبعون التلميح أم يتجاهلون؟ **الملاحظ:** هل التلميح العام مفيد دون كشف موقع؟ هل يخلق تحالفاً مؤقتاً؟

### 3) نهاية ثنائية (10–14د)
حالتان تُختبران بالتناوب:
- **LastSurvivor:** يموت 3 ويبقى 1 → هل Spirit راضون عن Witness Score؟
- **MutualCollapse:** يموت الجميع (تآكل عالي) → لا فائز حي، تُعرض نتائج Spirit منفصلة → هل مفهوم أن لا أحد "فاز" على الأحياء؟

### 4) مقابلة الروح (5د)
اسأل Spirit فقط: هل شعرت بدور؟ هل Hint كان مؤثراً؟ هل تود اللعب كـ Spirit مرة أخرى؟

## البيانات

- Playtest ID: SPI-001
- زمن أول موت، عدد Echo/Spirit، توقيت Hint، أثره (هل غيّر حركة؟)

- استبيان 1–5: هل الروح محايدة؟ هل Witness Score واضح؟ هل MutualCollapse مفهوم؟

## أسئلة البحث

1. هل "لا عودة" (Resurrect معطل) يقلل الإحباط أم يزيده؟ هل يطالبون بالعودة؟
2. هل Hint العام يخلق توتراً دون تجسس؟
3. هل 5–7 Echo كافية لهدف شخصي في 10د؟
