# سيناريو 02 — مقايضة تكتيكية (Tactical Tradeoff)
**الحالة: PROPOSED | GATE-1.1 | الوكيل: Playtest Oracle + Balancer | يختبر: RULE-02 + RULE-05**

## الهدف
هل Transfer قرار تكتيكي ذو كلفة حقيقية، لا "زر هروب مجاني"؟ يختبر ذرية النقل، الشروط الخمسة، ووضوح النتائج الخمس (RULE-05).

## الإعداد (4 لاعبين، خريطة أكبر — 2م نطاق حاسم)

| العنصر | القيمة |
|---|---|
| Vitality | 100، تآكل 0.10 + 0.02/Collapse + 0.03/Debuff |
| Debuffs | حقيبة كل Debuff = ورقة +0.03/30ث قابلة للنقل — تنتهي ذاتياً |
| Betrayal | نقاط تُسجل — لا أثر — الميسر يسجل فقط |
| مسافة | دائرة 2م حول كل لاعب (حلقة حبل) — يجب التداخل للنقل |
| Endgame | اللاعبون يعرفون النتائج الخمس من بطاقة: Last/Collective/Time/Draw/Mutual |

## السيناريو (تدريجي)

### 1) تعليم Transfer بالفشل (0–5د)
الميسر يسمح بمحاولات نقل مفتوحة مبكرة — معظمها تفشل (لا Debuff/مسافة/تبريد). **الملاحظ:** هل يتعلم اللاعبون الشروط الخمسة دون تدريب مطول؟ سجل أسباب الرفض.

### 2) ضغط الموارد (5–10د)
3 Collapse متتالية (20ث) + سعة 3 Debuffs ممتلئة عند البعض. الآن النقل ضروري للبقاء. **الملاحظ:** هل يختار اللاعب هدفاً أضعف (predator) أم أقوى (survivor)؟

### 3) قرار النهاية (10–16د)
عند 3 أحياء، التصويت + حد 20د. شجّع اللاعبين على مناقشة النتيجة المتوقعة قبل التصويت. **الملاحظ:** هل يعرفون الفرق بين TimeLimit (فائز أعلى Vitality) وDraw (تعادل)؟

### 4) مراجعة الخيانة (بعد المباراة 10د)
اعرض سجل Betrayal/لاعب دون عقوبة. اسأل: "لو كانت 3 نقاط = عقوبة X، هل كنت ستنقل؟" — سجل افتراضات دون تطبيق.

## البيانات (إضافية لهذا السيناريو)

- Playtest ID: TAC-001
- عدد محاولات Transfer: ناجحة/مرفوضة按 سبب (NoDebuff/OutOfRange/Cooldown/TargetFull/Self)
- توقيت Transfer مقابل Collapse القادم — هل هو استباقي أم يائس؟
- Betrayal توزيع — هل هناك "ملك الخيانة" أم توزيع متوازن؟

## أسئلة البحث

1. هل 2م + 5ث + سعة 3 تخلق مقايضة حقيقية أم اختناق مصطنع؟
2. هل فهم النتائج الخمس (لا 3) يغير سلوك النهاية؟
3. ما العتبة النفسية حيث يتوقف اللاعب عن النقل حتى لو سيموت؟

## حدود الصلاحية

- Debuff نقل كامل (RULE-02) — لا نقل جزئي.
- لا تفاعل بين Combat وTransfer في هذا السيناريو.
