# سيناريو 01 — ضغط اجتماعي (Social Pressure)
**الحالة: PROPOSED | GATE-1.1 | الوكيل: Playtest Oracle | يختبر: RULE-01..02 + RULE-03 + Betrayal**

## الهدف
هل يخلق نظام Vitality+Collapse ضغطاً جماعياً يدفع للخيانة؟ يختبر **RULE-01** (تآكل + Collapse) و **RULE-02** (نقل ذري + Betrayal تكلفة) و **RULE-03** (تصويت عند 3 أحياء).

## الإعداد (4 لاعبين، مدة مستهدفة 12–16د)

| العنصر | القيمة |
|---|---|
| خريطة | غرفة مغلقة 2م نطاق Transfer (شريط قياس) |
| Vitality | بطاقات 100→0 (كل 10 نقاط بطاقة) — تنخفض يدوياً 0.10/ث + 0.02 لكل Collapse |
| Collapse | مؤقت مركزي: كل 20ث (أو 15ث عند 3 أحياء) — يوزع Debuff بطاقة +0.03 تآكل/30ث |
| Debuffs | 3 حد أقصى/لاعب — قابلة للنقل كاملة (RULE-02 Move) |
| المسافة | شريط 2م — لا نقل خارجها |
| التبريد | 5ث ساعة رملية/هاتف |
| Betrayal | حجر أسود/لاعب لكل نقل ناجح — لا أثر قبل دراسة العتبات |

## السيناريو (4 مراحل)

### 1) البداية — 4 أحياء (0–4د)
لا شرح استراتيجي. يبدأ الجميع 100. Collapse كل 20ث. الميسر يعلن فقط التآكل والـ Debuffs. **الملاحظ:** هل يسأل اللاعبون عن النقل قبل الشرح؟

### 2) الضغط الأول (4–8د)
بعد 2 Collapse، يشرح الميسر Transfer: "يمكنك إزالة آخر عبء ونقله لشخص ضمن 2م — تزيد خيانتك نقطة". **الملاحظ:** من ينقل أولاً؟ هل يتردد بسبب الحجر؟

### 3) التصويت عند 3 أحياء (8–12د)
عند موت أول لاعب (0 Vitality → Spirit)، يستمر حتى 3 أحياء → يفتح التصويت 20ث. يجب إجماع 3 × Yes لإنهاء جماعي. **الملاحظ:** هل يصوت المنهك Yes والمتماسك No؟ هل يفهمون أن الامتناع=No؟

### 4) النهاية (12–16د)
إما CollectiveSurrender أو استمرار حتى LastSurvivor/TimeLimit. Spirit يجمع Echo (أوراق في زاوية) + يرسل تلميح عام واحد.

## البيانات المطلوبة (PLAYTEST_PLAN §5)

- Playtest ID: SOC-001
- زمن موت أول لاعب، زمن كل نقل، سبب رفض (مسافة/تبريد/سعة/لا Debuff)
- Betrayal/لاعب، توزيع النتائج، معدل الانسحاب
- استبيان 1–5: فهم Vitality؟ Collapse≠موت؟ ما الذي ينتقل؟ كلفة Betrayal؟

## أسئلة البحث

1. هل 15ث عند 3 أحياء يخلق ذروة توتر كافية دون شعور بالظلم؟
2. هل Betrayal كتكلفة فقط (لا فوز) مفهوم قبل شرح العتبات؟
3. هل يحدث "اتفاق ضمني" على عدم النقل؟ ما الذي يكسره؟

## حدود الصلاحية

- لا Unity — يدوي — لا يُقاس الأداء.
- عتبات Betrayal غير مطبقة — أي اقتراح "عقوبة" يسجل كملاحظة لا قاعدة.
