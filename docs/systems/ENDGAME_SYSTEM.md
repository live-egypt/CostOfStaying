# Endgame System — v2.1
**الحالة: PROPOSED FOR PLAYTEST | RULE-03 وRULE-05**

عند بقاء ثلاثة لاعبين Alive، يفتح الخادم تصويت Collective Surrender لمدة 20 ثانية.

## نتيجة التصويت
- يتطلب الإجماع (3/3 Yes) لإنهاء المباراة جماعياً.
- No أو الامتناع أو disconnect أو timeout = رفض.
- عند الإجماع: تنتهي المباراة بنتيجة Collective Surrender؛ لا فائز فردي.
- عند الرفض: تعود المباراة إلى Running وتستمر فترات Collapse الخاصة بثلاثة أحياء (15ث أولية).
- التصويت يحدث مرة واحدة لكل مباراة في MVP.
- لا تمنح صحة إضافية بعد قبول التصويت؛ المباراة تنتهي فوراً.

## نتائج المباراة
1. Last Survivor: آخر لاعب حي يفوز.
2. Collective Surrender: نهاية جماعية بلا فائز فردي.
3. Time Limit: عند 20 دقيقة، أعلى Vitality بين الأحياء يفوز؛ التعادل Draw.
4. Mutual Collapse: إذا مات الجميع، لا فائز حي.

كل قرار وتصويت ومهلة ونتيجة يقررها الخادم.
