## تعارض v1
منح +15% صحة ثم إنهاء المباراة فوراً يجعل المكافأة بلا أثر. يجب حسم هل التصويت ينهي المباراة أم يبدأ مرحلة أخيرة قبل اعتماد الشفاء.

آلة حالات مقترحة: Running → VoteOpen → VoteResolved → FinalPhase أو Ending → Completed.

يجب تحديد: التعادل، انتهاء المهلة، الانقطاع، موت المصوت، التصويت المتكرر، شروط الفوز، ونتيجة انتهاء الوقت. الخادم يصدر القرار النهائي فقط.
