# Spirit System — v2.0
**الحالة: PROPOSED | RULE-04: TBD**

القيم الموروثة: همس نصي كل 25ث مجاني ≤60 حرفاً؛ تسريب موقع كل 40ث بتكلفة 30% لمدة 3ث؛ تشويش منطقة كل 60ث بتكلفة 50% ضمن 5م لمدة 4ث؛ تجدد الطاقة 10%/ث؛ رؤية 15م؛ لا تفاعل جسدي.

ملاحظة: الطاقة تستعاد خلال 3ث و5ث على التوالي، بينما cooldown أطول؛ لذلك cooldown هو المحدد غالباً. اختبر ما إذا كانت الطاقة مورداً ذا معنى.

يجب حسم هدف الروح، الولاء، من يرى التسريب، نطاق الهمس، وعلاقتها بنتيجة المباراة. الخادم يحسم الطاقة والتبريد والأهداف. لا تقبل قيم العميل.
