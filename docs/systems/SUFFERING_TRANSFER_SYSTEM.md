# Suffering Transfer — v2.0
**الحالة: PROPOSED | RULE-02: TBD**

الشروط الأولية: المصدر والهدف Alive، هدف مختلف، Debuff نشط قابل للنقل، مدى 2م، تبريد 15ث، المباراة Running.

## معاملة ذرية على الخادم
تحقق هوية اللاعب وMatchId وRequestId → تحقق الحالة والمدى والتبريد وDebuff → تحقق سياسة التكديس → نفذ النقل وفق RULE-02 → حدّث المصدر والهدف ونقاط الخيانة معاً → خزّن RequestId → أرسل الحدث.

إذا فشل تحقق واحد فلا تتغير حالة أي طرف. لا تقبل مسافة أو نتيجة محسوبة من العميل. استخدم rate limit وRequestId لمنع replay والتزامن.
