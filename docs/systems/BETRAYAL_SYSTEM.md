# Betrayal System — v2.1
**الحالة: PROPOSED FOR PLAYTEST**

كل نقل معاناة ناجح يضيف نقطة Betrayal واحدة إلى المصدر. هذه النقاط تمثل كلفة أخلاقية/ميكانيكية وليست نقاط مكافأة أو نقاط فوز.

المستويات الموروثة من v1:
- 3 نقاط: +15% شدة الانهيارات القادمة.
- 5 نقاط: تقليل فترة الراحة (المقدار TBD).
- 7+ نقاط: تسريع الانهيارات (المقدار TBD).

يطبق الخادم المستويات ولا يضاعف المعدلات بلا حد. يجب تعريف ما إذا كانت الآثار تراكمية أو تستبدل الأعلى قبل اعتماد التوازن. لا تمنح نقاطاً للمحاولات الفاشلة، ولا تمنح Betrayal نقاط فوز.

اختبارات الحدود: 0، 2، 3، 4، 5، 6، 7، الحد الأقصى، replay، concurrency، وتحقق من عدم وجود تضاعف غير مقصود.
