# Collapse System — v2.0
**الحالة: PROPOSED**

لكل لاعب Alive مؤقت مستقل يدار على الخادم. عند انتهائه يختار الخادم Debuff صالحاً ويطبقه ثم يحدد الموعد التالي. لا يعالج الانهيار لاعباً ميتاً أو خارج المباراة.

الفترات الموروثة أولياً: 8+ أحياء 30ث، 6–7 25ث، 4–5 20ث، 3 15ث، 2 12ث.

## إعادة الجدولة
لم تعتمد قاعدة التوقيت عند تغير عدد الأحياء. خيار اختبار يحافظ على نسبة الوقت المتبقي:
RemainingRatio = clamp((NextCollapseAt - Now) / OldInterval, 0, 1)
NewNextCollapseAt = Now + RemainingRatio * NewInterval

## متطلبات Debuff
لكل نوع تعريف للقيمة، التكديس، الحد الأقصى، المدة، قابلية النقل، والإحصاء المتأثر. لا تكديس غير محدود.

## القبول
مؤقت مستقل؛ إعادة جدولة صحيحة؛ لا تكرار للحدث؛ لا client clock؛ معالجة آمنة لتزامن الموت مع انتهاء المؤقت.
