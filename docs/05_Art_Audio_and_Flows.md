**المشروع:** ثمن البقاء

---

## 1. التوجه الفني

**الأسلوب:** 3D Low-Poly مظلم (Dark Low-Poly)

**الكلمات المفتاحية:** Oppressive, Decayed, Unsettling, Heavy, Cold

**الألوان الرئيسية:**
- رمادي داكن
- أحمر دامٍ باهت
- أخضر مريض
- أسود
- لمسات صفراء باهتة للإضاءة الضعيفة

**الشخصيات:**
- اللاعب الحي: مظهر متعب، ملابس عملية متسخة، غير بطولي
- الروح: شفافية منخفضة التكلفة (يفضل Dithered أو Fresnel بدل Alpha Blend الكامل) + حركة بطيئة

**البيئة:** مبنى/مستشفى مهجور، ممرات ضيقة، إضاءة محدودة، ضباب خفيف.

**واجهة المستخدم:** بسيطة، باهتة، تُظهر الانهيار ونقاط الخيانة وطاقة الروح بوضوح.

---

## 2. التوجه الصوتي

- نبض قلب يتغير حسب الحالة
- أصوات انهيار منخفضة ومزعجة
- همسات بعيدة
- صمت ثقيل في لحظات
- موسيقى قليلة جداً أو معدومة في أغلب الوقت

---

## 3. مخططات التدفق الأساسية

### تدفق الانهيار
بدء الجولة → مؤقت فردي لكل لاعب → انتهاء المؤقت → اختيار نوع عشوائي → تطبيق على السيرفر → إرسال Delta → تحديث UI وتأثيرات → إعادة المؤقت (حسب عدد الأحياء)

### تدفق نقل المعاناة
ضغط الزر → تحقق محلي سريع → Request إلى السيرفر → تحقق كامل (مسافة + تبريد + Debuff) → نقل + تسجيل خيانة → إرسال التحديثات

### تدفق القتال
ضغط الهجوم → RequestFire → تحقق سيرفر (زاوية + مدى + ذخيرة) → Raycast → تطبيق ضرر + تسريع انهيار → تأثيرات

### تدفق الموت والروح
صحة = 0 → تأكيد السيرفر → تحويل الحالة إلى Spirit → إخفاء الجسد + إظهار الروح → تفعيل الطاقة والأفعال

### تدفق النهاية
تحقق دوري → 3 أحياء؟ → بدء تصويت 20ث → 2/3 موافقة؟ → نعم: شفاء +15% ثم نهاية | لا: تسارع واستمرار → أو انهيار الجميع / انتهاء الوقت
