# مواصفات قواعد اللعبة — v2.0
**الحالة: PROPOSED؛ القرارات الخمسة أدناه TBD**

## قواعد موروثة من v1 (أرقام أولية)
- مؤقت Collapse مستقل لكل لاعب.
- الفترات المقترحة حسب عدد الأحياء: 8+ = 30ث، 6–7 = 25ث، 4–5 = 20ث، 3 = 15ث، 2 = 12ث.
- Debuffs: Max Health، Movement Speed، Aim، Vision، Hearing، Turn Rate.
- نقل المعاناة: مدى أولي 2م وتبريد أولي 15ث.
- الإصابة تسرّع الانهيار التالي 20% كقيمة أولية.
- تصويت عند 3 أحياء، 20ث، وعتبة 2/3 كقاعدة سابقة.
- حد المباراة الأقصى المقترح 20 دقيقة.

## القرارات المعلقة
| ID | السؤال | خيارات مطروحة | توصية للاختبار |
|---|---|---|---|
| RULE-01 | ما مصدر الموت؟ | استنزاف مستمر / انهيارات تخفض الصحة / مزيج | مزيج واضح قابل للقياس |
| RULE-02 | كيف ينتقل Debuff؟ | نقل كامل / نسخ / تخفيف | نقل كامل لعنصر واحد في prototype |
| RULE-03 | ماذا يفعل تصويت 3 أحياء؟ | إنهاء / مرحلة أخيرة | اختبار الخيارين |
| RULE-04 | ما هدف الروح؟ | محايدة / معادية / مستقلة | دور مستقل محدود |
| RULE-05 | ما شروط الفوز؟ | آخر حي / أهداف جماعية / نتائج متعددة | تعريف نتيجة لكل لاعب قبل MVP |

## قواعد تنفيذية
كل المؤقتات على ساعة خادم monotonic. الخادم يحسم الصحة والضرر والنقل والطاقة والتصويت والنتيجة. عند تغير عدد الأحياء يجب تطبيق سياسة إعادة جدولة موحدة. لا تعتمد أي قيمة توازن نهائية قبل Playtest.
