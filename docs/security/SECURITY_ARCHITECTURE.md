# Security Architecture — v2.1
**الحالة: PROPOSED | تتبع ADR-002 ولا تثبت تنفيذاً**

الأصول: حالة المباراة، الجلسات، نتائج المباريات إن حُفظت لاحقاً، خادم اللعبة، مفاتيح التوقيع، artifacts، والمستودع.

المبادئ: سلطة الخادم وفق ADR-002، أقل صلاحية، التحقق من كل مدخل، الرفض افتراضاً، حدود معدل، منع الإعادة، أسرار خارج Git، وسجلات لا تكشف البيانات الحساسة.

Anti-cheat لا يعوض سلطة الخادم. العميل غير موثوق.

بوابة الإصدار مستقبلية: لا Critical/High مفتوحة دون قبول مخاطر موثق، ولا أسرار في Git أو artifacts. هذه البوابة لم تُجتز.
