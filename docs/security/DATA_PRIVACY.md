# Data Privacy — v2.0
**الحالة: PROPOSED**

اجمع أقل قدر من البيانات اللازمة للحساب والمباراة والتشغيل. لا تجمع الموقع الدقيق أو جهات الاتصال أو معرفات إعلانية دون حاجة معلنة وموافقة مناسبة.

البيانات المحتملة: معرف حساب، اسم عرض، سجل مباراة مختصر، إعدادات، ومقاييس تشغيل. التصنيف النهائي ومزود التخزين وموقعه ومدد الاحتفاظ TBD.

قبل الإطلاق: سياسة خصوصية، توضيح الغرض والاحتفاظ والمشاركة، آلية حذف/تصدير عند الانطباق، حماية النقل والتخزين، ومراجعة المتطلبات القانونية حسب الأسواق. هذه الوثيقة ليست رأياً قانونياً ولا تثبت الامتثال.
