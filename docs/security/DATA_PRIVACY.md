# Data Privacy — v2.1
**الحالة: PROPOSED | ليست رأياً قانونياً ولا تثبت الامتثال**

اجمع أقل قدر لازم. لا تجمع الموقع الدقيق أو جهات الاتصال أو معرفات إعلانية دون حاجة معلنة وموافقة مناسبة.

البيانات المحتملة لاحقاً: معرف حساب، اسم عرض، سجل مباراة مختصر، ومقاييس تشغيل. المزود والموقع ومدد الاحتفاظ TBD وتتبع ADR-003. لا حفظ إنتاجي قبل ذلك.

قبل الإطلاق: سياسة خصوصية، توضيح الغرض والاحتفاظ، وآلية حذف أو تصدير عند الانطباق. هذه الوثيقة لا تثبت أن ذلك تم.
