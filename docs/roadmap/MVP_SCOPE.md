# MVP Scope — v2.0
**الحالة: PROPOSED**

داخل النطاق: 4 لاعبين، خريطة واحدة، تحكم لمس، Collapse، Transfer، Betrayal، Combat أساسي، Spirit، Endgame ونتيجة واضحة، Dedicated Server، Android build قابل للاختبار.

خارج النطاق: 8–16 لاعباً، خرائط متعددة، متجر، اقتصاد دائم، Meta progression، voice chat، iOS production، مكافحة غش تجارية.

بوابة الدخول: اعتماد RULE-01..05، Domain Core واختباراته، لاعبان على جهازين، ثم vertical slice لأربعة لاعبين.

تعريف الاكتمال: مباراة كاملة تبدأ وتنتهي بقواعد محددة، دون crash أو فساد حالة، مع reconnect محدد، واختبارات وأدلة أمن وأداء.
