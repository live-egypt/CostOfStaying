# نطاق MVP — v2.1
**الحالة: PROPOSED | المنصة: Android أولاً**

## الهدف
إثبات حلقة مباراة كاملة لأربعة لاعبين على خريطة واحدة، مع خادم مستقل يملك حالة المباراة. هذا النطاق لا يعني أن التكدس التقني أو القواعد قد اعتمدا نهائياً.

## داخل النطاق
- 4 لاعبين وخريطة واحدة.
- تحكم لمس أساسي وواجهة حالة واضحة.
- Vitality وCollapse وDebuffs.
- Suffering Transfer ذري وBetrayal.
- Combat أساسي محدود.
- Spirit وEcho Fragments وتلميحات عامة محدودة.
- Endgame vote ونتائج المباراة.
- Android client وخادم Linux تجريبي إذا اجتاز ADR-001 prototype.

## خارج النطاق
8–16 لاعباً، خرائط متعددة، متجر، اقتصاد دائم، Meta progression، Voice Chat، iOS production، Backend دائم قبل إثبات الحاجة، وAnti-cheat تجاري.

## بوابات الدخول
1. مراجعة واعتماد قواعد قابلة للتنفيذ بعد Playtest.
2. حسم ADR-001 عبر بناء Android وLinux prototype.
3. بناء Domain Core واختبار قواعده دون اعتماد على المحرك.
4. اختبار اتصال لاعبين على جهازين مختلفين.
5. Vertical Slice لأربعة لاعبين.

## تعريف الاكتمال
مباراة تبدأ وتنتهي وفق قواعد معلنة؛ لا crash أو فساد حالة في سيناريو القبول؛ reconnect وفق سياسة محددة؛ واختبارات وأدلة أمن وأداء واستقرار قابلة للمراجعة.
